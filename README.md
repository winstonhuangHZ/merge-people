# 合成领导人

[在线游玩](https://winstonhuanghz.github.io/merge-leaders/) · 也可以直接用浏览器打开 `index.html`。鼠标移动后点击投放；触屏拖动后松手投放。键盘左右键调整位置，空格投放，R 重开。点击「等级图鉴」查看所有等级，打开图鉴期间游戏暂停。最高分保存在当前浏览器。

每局有 3 枚炸药。点击「炸药」或按 B 选择，再点击或触屏投放；再点一次按钮可取消选择。炸药约 2 秒后爆炸，以加强至原版 5 倍的推力推开全场，而不直接删除人物。合成一个习近平（LV 9）奖励 1 枚炸药。引信燃烧期间不能再次投放炸药，但可以继续投放普通人物。

合成顺序：毛泽东 → 周恩来 → 刘少奇 → 华国锋 → 邓小平 → 江泽民 → 朱镕基 → 胡锦涛 → 习近平 → 姆巴佩毛装彩蛋 → 59 式坦克。两辆坦克碰撞会清除并奖励分数和复活币。人物顺序是游戏设定，并非历史地位排序。

人物形象由 AI 根据维基共享资源标为公有领域或 CC0 的照片生成，衣服及身体等细节为生成内容，并非历史照片；最后的坦克也是生成图。参考照片和原游戏来源见 `SOURCES.md`。本游戏衍生自 [YHSome/BigNaiWa](https://github.com/YHSome/BigNaiWa)。

物理引擎沿用并修改原项目：把位置纠偏与速度分离，堆叠受压时积累应力、在附近合成时有限释放，并对坦克炮管增加碰撞点。精细的凹凸轮廓仍可能卡住其他物体；碰撞使用多个圆近似，视觉轮廓不能完全对应。

## 验证

安装 Node.js 后，可运行 `node tests/bomb.test.js`、`node tests/stability.test.js`、`node tests/gameplay.test.js` 和 `node tests/physics.test.js`。
